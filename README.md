# 幣安永續合約「結構雙引擎二拍突破（去過擬合・零前視偏差修正版）」

針對原版 v8 存在的 **樣本內小數點曲線擬合、寫死 `AKEUSDT`、事後低量妖幣存活者偏差、同根 K 線幽靈保本成交 Bug、實盤未收線誤報、以及全倉 3x 滾倉高爆倉風險** 進行全面量化重構。

## 🛡️ 核心修正與雙引擎 0% 重疊結構設計

1. **廢除單根 10x~34x 天量追高與 60+ 個小數點補丁，統一採用「整數結構二拍確認 + 天量衰竭防護」**：
   - **★ 引擎 A（水上高台黏帶二拍 `STAGE2_SHELF_BREAKOUT`）**：`MA200` 上揚且前 `80` 根收盤全數穩守 `MA200` 之上 + 前 `8` 根內 7 條均線 (`MA7 ~ MA120`) 黏帶收斂 `<= 2.0%` + `20` 根箱體 `<= 5.0%` → 第一拍 `2~8x` 溫和放量紅 K 收破箱頂 (`CLV >= 0.70`) + `1~4` 根內不破 `MA25`，且第二拍溫和放量 (`2~10x`，拒絕 `>10x` 天量趕頂針、漲幅 `>= 1%`、`CLV >= 0.70`) 同時收過前 `60` 根區間前高確認。
   - **🐂 引擎 B（水下築底穿 MA200 二拍 `COILED_MA200_STAGE2`）**：突破前連續 `>= 80` 根收盤位於 `MA200` 水下築底 + 長均線走平止跌 + 7 條均線黏帶 `<= 2.0%` → 第一拍 `2~8x` 紅 K 收上 `MA200` (`CLV >= 0.70`, 乖離 `<= 3.5%`) + `1~4` 根內穩守 `MA200` 且第二拍溫和放量 (`2~10x`, 漲幅 `>= 1%`) 確認。
2. **大盤短線共振與流動性零前視驗證**：
   - 訊號觸發當下強制要求 `BTCUSDT` 15m 收盤站穩 `MA25` 之上（排除大盤陰跌時的逆勢假突破），且 **前 24 小時真實滾動成交額 `>= $5,000,000 USDT`**，與實盤掃描器 `fetch_top_usdt_perps` 100% 對齊。
3. **消除同根「幽靈保本」與低估摩擦成本**：
   - 止損與保本觸價一律以 `min(Open, StopPrice)` 計入開盤跳空滑價；保本鎖利僅在 **K 線收盤價正式站上 `+1.5R`** 後才於下一根生效，徹底消除同根先衝高又跌破的假保本。
   - 來回手續費與滑價設為 **`0.24%`**，並按實際持倉時間扣除每 8 小時 **`0.01%`** 永續資金費率。
4. **固定風險分倉取代全倉 3x 滾倉**：
   - 採用 **單筆 `1.5%` 帳戶固定風險預算**（A/B 引擎各最多 2 倉、單倉上限 `2.0x` 名目槓桿）。
   - **365 天實測（203 筆訊號、執行 138 筆）**：累積 **`+92.4R`**、PF **`1.86`**（扣除前 2 大極端值後 PF **`1.35`**），`1.5%R` 分倉由 `$1,000` 成長至 **`$2,481.52` (`+148.2%`, 最大回撤僅 `-13.1%`)**。
   - **90 天實測（63 筆訊號、執行 39 筆）**：累積 **`+44.7R`**、PF **`2.32`**（扣除前 2 大極端值後 PF **`1.65`**），`1.5%R` 分倉成長至 **`$1,611.95` (`+61.2%`, 最大回撤僅 `-12.9%`)**。
