# 幣安永續合約「結構雙引擎二拍突破（去過擬合・零前視偏差修正版）」

針對原版 v8 存在的 **樣本內小數點曲線擬合、寫死 `AKEUSDT`、事後低量妖幣存活者偏差、同根 K 線幽靈保本成交 Bug、實盤未收線誤報、以及全倉 3x 滾倉高爆倉風險** 進行全面量化重構。

## 🛡️ 核心修正與雙引擎 0% 重疊結構設計

1. **廢除單根 10x~34x 天量追高與 60+ 個小數點補丁，統一採用「整數結構二拍確認」**：
   - **★ 引擎 A（水上高台黏帶二拍 `STAGE2_SHELF_BREAKOUT`）**：`MA200` 上揚且前 `80` 根收盤全數穩守 `MA200` 之上 + 前 `8` 根內 7 條均線 (`MA7 ~ MA120`) 黏帶收斂 `<= 2.0%` + `20` 根箱體 `<= 5.0%` → 第一拍 `2~8x` 溫和放量紅 K 收破箱頂 (`CLV >= 0.70`) + `1~4` 根內不破 `MA25` 且第二拍放量 (`>= 2x`, 漲幅 `>= 1%`, `CLV >= 0.70`) 再創收盤新高確認。
   - **🐂 引擎 B（水下築底穿 MA200 二拍 `COILED_MA200_STAGE2`）**：突破前連續 `>= 80` 根收盤位於 `MA200` 水下築底 + 長均線走平止跌 + 7 條均線黏帶 `<= 2.0%` → 第一拍 `2~8x` 紅 K 收上 `MA200` (`CLV >= 0.70`, 乖離 `<= 3.5%`) + `1~4` 根內穩守 `MA200` 且第二拍放量 (`>= 2x`, 漲幅 `>= 1%`) 確認。
2. **消除流動性前視與存活者偏差**：
   - 移除私人電腦快取路徑與寫死塞入的 `AKEUSDT`。
   - 訊號觸發當下強制檢查 **前 24 小時（96 根已收盤 15m）真實滾動成交額 `>= $5,000,000 USDT`**，與實盤掃描器 `fetch_top_usdt_perps(min_quote_vol=5_000_000)` 100% 對齊。
3. **消除同根「幽靈保本」與低估摩擦成本**：
   - 止損與保本觸價一律以 `min(Open, StopPrice)` 計入開盤跳空滑價；保本鎖利僅在 **K 線收盤價正式站上 `+1.5R`** 後才於下一根生效，徹底消除同根先衝高又跌破的假保本，並移除 `j == i + 3 and -1.8%` 的湊參數補丁。
   - 來回手續費與滑價提高至 **`0.24%`**，並按實際持倉時間扣除每 8 小時 **`0.01%`** 永續資金費率。
4. **實盤掃描器與回測 100% 同源**：
   - 掃描器預設 `drop_forming=True` 僅評估已收盤 K 線，杜絕盤中插針誤報。
   - 共用 `BTCUSDT` 大盤急殺保護、同根集體插針過濾（`< 3` 檔）與非字母序優先級排序（消除 `A` 開頭幣種優先成交偏誤）。
5. **固定風險分倉取代全倉 3x 滾倉**：
   - 採用 **單筆 `1.5%` 帳戶固定風險預算**（A/B 引擎各最多 2 倉、單倉上限 `2.0x` 名目槓桿，總敞口風險上限 `6%`）。365 天實測（300 筆訊號、執行 195 筆）累積 **`+90.4R`**、PF **`1.55`**（扣除前 2 大極端值後 PF **`1.22`**），`1.5%R` 分倉穩健獲利 **`+85.3%` (MDD `-22.4%`)**，而無腦全倉 3x 滾倉則因波動率拖累虧損 **`-86.1%` (MDD `-92.2%`)**。
